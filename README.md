## Description
The project uses a CI/CD pipeline with GitHub Actions to automatically build, test, and deploy a Dockerized application.

## CI/CD Pipeline
The pipeline includes:
- Build Docker image
- Run tests (optional)
- Push image to Docker Hub

## How to Run Locally
1. Clone repo:
   git clone https://github.com/tayyabarehman123/DevOps-Team-Project-Deliverables.git

2. Build Docker image:
   docker build -t myapp .

3. Run container:
   docker run -p 5000:5000 myapp

## Deployment
- Automatically deployed via GitHub Actions
- Runs on Docker Hub using Docker
